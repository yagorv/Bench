# Fixed task context
`inputs/events.csv` is generated from the task seed and requested row count. Columns are `record_id,email,event_time,amount`. First occurrence means earliest row in source order. Trim email and lowercase it, then accept it only if it matches exactly `^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$`. Normalize timestamps to UTC with second precision and a trailing `Z`; normalize amount to two decimal places. Reject invalid email records before duplicate handling. Trim record IDs. Count invalid rows and duplicate valid IDs separately. Canonical output order is timestamp then record ID. Process the source incrementally; do not keep the full source dataset in memory.
