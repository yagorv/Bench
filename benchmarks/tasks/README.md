# Exámenes para agentes

Para ejecutar un examen manualmente, usa las carpetas autocontenidas de [`exams/`](../../exams/). Cada una ya contiene el enunciado, contexto, entradas y archivos iniciales que se entregan al agente. No necesitas ejecutar `agentbench prepare`.

Este directorio contiene las fuentes del benchmark y sus evaluadores. No entregues sus carpetas directamente a los agentes: algunas incluyen respuestas esperadas y pruebas ocultas.
