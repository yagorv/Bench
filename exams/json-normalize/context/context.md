# Fixed task context
`inputs/records.jsonl` is a fixed dataset of 1,000,000 JSON Lines records. Each line contains an object with `id`, `email`, and numeric `amount`. The dataset contains 900,000 distinct IDs, repeated IDs, and invalid emails; source order is deliberately not sorted by ID. Normalize an email by trimming surrounding whitespace and lowercasing it. A valid email has exactly one `@`, non-empty local and domain parts, and a dot in the domain. Ignore invalid-email rows before duplicate handling. For each ID, retain its first valid row in source order; if earlier rows for that ID have invalid emails, retain the first later valid row. Sort retained records by ID in ascending lexicographic order. The output is JSON Lines with exactly the three source fields and one compact JSON object per line. Preserve numeric amounts without rounding. The correct output has 900,000 records.
